# YOGA WEEKEND — GitHub Pages

1. Распакуйте архив и загрузите **содержимое** в корень репозитория GitHub (не папку `github-pages-ready`).
2. В репозитории откройте Settings → Pages. Выберите Deploy from a branch, ветку `main` и каталог `/ (root)`, затем сохраните.
3. Дождитесь ссылки в Settings → Pages. Сайт работает как на `username.github.io`, так и на `username.github.io/repository/`.

Если позже будете использовать домен `yoga-weekend.azhidkov.pro`, сначала добавьте его в настройках GitHub Pages, затем поменяйте DNS с адреса Sites на целевой адрес GitHub Pages. Не публикуйте один и тот же домен на двух площадках одновременно.
